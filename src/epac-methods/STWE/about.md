# STWE  (Standard Two-Way Encryption)

STWE (Standard Two-Way Encryption) is a minimalistic experimental encryption system developed mostly for **education purposes**.

The main goal of the project is to show the mathematical and logical principles of such systems in practice. It provides an example of how plaintext data can be encrypted, and then decrypted back to the initial state.

As you've probably already understood, STWE is not meant to be used against modern cryptography algorithms or secure sensitive data. Instead, it provides a tool for experimenting and learning how reversible transformations work.

Also, the project initially started for a very simple reason: **I was bored and needed some placeholder cipher.** What resulted as an experiment turned into educational project that can be useful for anyone interested in the subject.

> **Note:** STWE is an experimental/educational cipher and is not supposed to be used for securing sensitive or confidential information.
